# WheelOS Organization Profile

This repository contains the public GitHub Organization profile and shared
reference documentation for [WheelOS](https://github.com/wheelos).

## Repository scope

- `profile/README.md` — Organization profile shown on GitHub
- `profile/HardWare.md` — Hardware support matrix
- `profile/Software.md` — Software and platform references
- `profile/Evaluation.md` — Autonomous-driving evaluation metrics
- `profile/Awesome.md` — Curated autonomous-driving resources
- `profile/images/` — Images used by the hardware documentation
